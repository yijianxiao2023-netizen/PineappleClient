WHAT'S INSIDE

Everything you need on screen

Every module can be turned on or off from the in-game menu. Just press RETURN anywhere in the world.

Info HUD

Live FPS, XYZ coordinates, the direction you're facing, and left/right clicks per second in the top-left corner.

Keystrokes

W, A, S, D, left click, right click and space light up as you press them. Great for recording PvP.

Zoom C

Hold to zoom 2× to 10×, with smooth cinematic camera while zoomed.

Fullbright G

See in caves and at night without torches or night vision.

Armor HUD

Your armor and held item at the side of the screen, with durability counts that turn yellow and then red as they wear down.

Own launcher

Installs Minecraft, Fabric and Fabric API for you in a separate folder. Microsoft or offline login, RAM slider, extra mods.

INSTALL ON MAC

Up and running in a minute

You need a Mac with Apple Silicon (M1 or newer) and a copy of Minecraft Java Edition that you own.

Download the .dmg

Click the download button and open PineappleClient.dmg.

Drag to Applications

Drag the pineapple onto the Applications folder.

Open it the first time

The app isn't notarized yet, so right-click it and choose Open, then Open again. If macOS still blocks it, go to System Settings → Privacy & Security and click Open Anyway.

Press PLAY

Sign in, leave 1.21.1 + Fabric checked, and hit PLAY. The first launch downloads the game.

FAQ

Questions

Is it free?

Yes. PineappleClient is open source under the Apache 2.0 license. You still need to own Minecraft Java Edition.

Can I play on servers like Hypixel?

Yes, once you sign in with your Microsoft account. Offline mode only works in singleplayer and on offline-mode servers. The HUD, keystrokes and zoom are standard features, but some servers don't allow fullbright, so check each server's rules.

Will it mess with my normal Minecraft?

No. Everything is installed into its own folder (~/Library/Application Support/pineappleclient), separate from .minecraft.

Can I add other mods like Sodium?

Yes. Click Add mod jar… in the launcher and pick any Fabric 1.21.1 mod.

Windows or Linux?

The .dmg is for macOS only. On Windows or Linux, download the source from GitHub and run launcher/start.bat or start.sh.

macOS says the app is damaged or from an unidentified developer

Use right-click → Open, or run xattr -cr /Applications/PineappleClient.app in Terminal once.
